# SmallPad
A small notepad app written in C#, compatible with Windows 7 and later. Inspired by [TinyRetroPad](https://github.com/PlummersSoftwareLLC/TinyRetroPad) but not programmed by AI. Will obviously be over 4 KB due to .NET Framework.

# Features

- Full support for *.txt and *.rtf formats.
- Find and replace any text within a document.
- Insert pictures, date and time within a document.
